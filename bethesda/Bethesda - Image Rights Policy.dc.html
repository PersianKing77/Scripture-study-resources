Image Rights Policy

The Pool of Bethesda, Jerusalem — an interactive atlas

This product ships with no third-party photography or map imagery embedded in it. It supports one optional feature — an aerial-imagery overlay — that fetches tiles from a service the user supplies. This policy governs that feature and its in-product rights gate.

1. What is gated

Before the "Custom tile service" field accepts a URL, the user must check a box confirming they hold a commercial license for that service and accept responsibility for its use. The field is disabled and the underlying fetch code refuses to run until that box is checked, on every session (the confirmation is not carried over silently between browsers or devices).

2. Why this exists

Commercial satellite and aerial imagery is almost always licensed per-seat or per-request. A product that fetched a default provider's tiles for every visitor would create licensing exposure the Publisher does not control. Gating the feature behind an affirmative, per-session confirmation keeps that exposure with the user who supplies the service, not the Publisher.

3. Illustrations and diagrams already in the product

All plans, sections, and axonometric views of the site are original line drawings redrawn from published excavation reports (see the Credits panel and the Feature Provenance Workbook); none are traced from or reproduce a copyrighted photograph or third party's illustration.

4. If a user submits an image

This product does not currently accept user-submitted images anywhere in its interface. If an image-upload feature is added later, this policy should be extended to require the same affirmative rights confirmation before the image is accepted, plus a takedown contact.
