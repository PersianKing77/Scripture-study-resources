Privacy Notice

The Pool of Bethesda, Jerusalem — an interactive atlas

This product is a static, offline-capable web page. It is built to need as little of your data as possible, and this notice explains exactly what it does and does not collect.

What this product stores, and where

Your browser's local storage, on your own device, keeps two things so the page remembers your place: the last building phase you viewed (localStorage key bethesda.lastPeriod), and — only if you type one in — the address of a custom satellite-imagery tile service (bethesda.tileUrl). The rights-confirmation checkbox for that field is not stored anywhere; it resets to unchecked every time the page loads. None of this ever leaves your device; the product has no server to send it to.

Optional third-party imagery

No aerial imagery is bundled with or fetched by this product by default. If you choose to enter the address of a tile service you hold a license for, your browser will request map tiles directly from that service, which will see your IP address the way it would for any web request. That exchange is between you and the imagery provider; the product does not proxy, log, or see it.

Analytics, cookies, accounts

None. This product sets no cookies, runs no analytics or tracking script, and has no account system, sign-in, or server-side log of any kind.

Fonts and runtime libraries

The online build requests two typefaces from fonts.googleapis.com and fonts.gstatic.com, in the ordinary way any web font works, and loads React, ReactDOM, and Babel from unpkg.com to run the page. The offline build embeds the fonts and these libraries directly and makes none of those requests, except that a user-entered tile URL can still make a remote request in either build. See the font notices in the product's Credits panel.

Children

This product is intended for general and educational audiences and does not knowingly collect personal information from anyone, including children, because it does not collect personal information from anyone.
