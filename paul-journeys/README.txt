THE JOURNEYS OF PAUL: AN INTERACTIVE STUDY ATLAS
Beta release
Build date: 2026-09-09

CONTENTS
  index.html                    Online edition (loads Leaflet from its CDN; the coastline data,
                                 the full World English Bible New Testament text, and every other
                                 content file are bundled locally — no scripture text is fetched
                                 over the network).
  Pauls-Journeys-offline.html   Offline edition. Fully self-contained: open directly from disk
                                 with no network connection. Same data, code, and content as
                                 the online edition.
  Pauls-Journeys-devices.html   Phone/tablet device-frame preview harness (loads index.html in
                                 iframes at common device sizes). Not required to run the atlas.
  app.js, data/                 Application logic and content data used by index.html, including
                                 data/web-nt.js (the bundled WEB New Testament text).
  THIRD_PARTY_NOTICES.txt       Required license notices for bundled third-party software,
                                 data, and fonts.
  licenses/OFL-1.1.txt          Complete, unmodified SIL Open Font License 1.1 text for the
                                 bundled EB Garamond and IBM Plex fonts.

STATUS
  This is a beta. The atlas presents a schematic educational reconstruction based on selected
  published research; see the About and Terms of Use tabs in the application for the full
  disclosure, license terms, and scripture-text note.

READING
  Every cited verse and full chapter (Gospels, Acts, and the epistles) opens in place in the
  side panel from the bundled World English Bible text — no link-out, no network call. Use the
  "Read" button (or the "Read" tab in the phone bottom bar) to browse the full reading plan.
