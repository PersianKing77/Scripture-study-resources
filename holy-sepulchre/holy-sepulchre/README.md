# The Holy Sepulchre: A Site Chronology — beta edition

## System requirement

Internet connection required when opening this site chronology. The current beta loads
its display runtime and fonts from trusted content-delivery networks
(unpkg.com, fonts.googleapis.com — see `THIRD_PARTY_NOTICES.txt`) and is not
offline-capable.

## Opening the site chronology

Open `Holy Sepulchre Site Chronology.dc.html` in a modern desktop or mobile
browser with JavaScript enabled. If it does not load within a few seconds,
check your connection and make sure your network allows unpkg.com and
fonts.googleapis.com, then reload.
